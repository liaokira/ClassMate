# ClassMate

ClassMate is a **social collaboration platform** designed to help students connect, organize, and communicate efficiently. It offers a robust set of features to enhance academic collaboration.

## 🎯 Features

- **👤 User Profiles** – Create and update personal profiles with a biography, profile picture, and a list of classes.
- **📚 Study Groups** – Discover, join, and manage study groups tailored to specific classes or interests. Engage in discussions and collaborate on coursework.
- **🤝 Friend Management** – Search for friends by email, send friend requests, and maintain a personal friends list.
- **💬 Real-Time Messaging** – Engage in **live group messaging** or **private direct messaging** using WebSocket-based communication for instant updates.
- **📅 Scheduling & Classes** – Organize your academic life by adding and managing classes and keeping track of your schedule.
- **🔐 Secure & Scalable** – Built with **JWT-based authentication** and a **PostgreSQL backend**, ensuring secure data transactions and scalability for growing user communities.
